# Credits and external components

Flotsam Plus is an independent companion plugin for Flotsam.

- **Flotsam** belongs to its creators and rights holders. The game assembly
  is required locally for compilation and is not distributed in this repository.
- **BepInEx** provides plugin loading and configuration:
  https://github.com/BepInEx/BepInEx
- **Harmony / HarmonyX** provides runtime method patching through the
  `0Harmony.dll` supplied with BepInEx:
  https://github.com/BepInEx/HarmonyX
- **Unity** provides the engine API used by Flotsam:
  https://unity.com/
- The existing **Flotsam Trainer** by **Hansjoy / Hansjoys** inspired the
  companion workflow and can be used alongside this plugin:
  https://www.nexusmods.com/flotsam/mods/10

The original trainer and the dependency DLLs are not included. The MIT
license in this repository applies to this plugin's code and documentation.
