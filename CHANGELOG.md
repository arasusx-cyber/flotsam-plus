# Changelog

## 1.1.0 — 2026-11-07

- Four Polish menu tabs: ship, residents, construction/research and resources.
- Independent ship speed, turning, physical acceleration and braking controls.
- Energy-free travel and reversible ship tuning.
- Instant new construction, boats and upgrades using native game branches.
- Research speed multiplier from 1 to 100.
- Suppression of new nighttime sleep projects; active sleep finishes normally.
- Per-feature compatibility handling, 21 logic checks and 43 game API/IL checks.
- Compiled and checked automatically; gameplay validation is still pending.

## 1.0.0 — 2026-11-07

- Independent hunger and thirst switches for the player's town.
- Polish F8 menu with saved need settings and a configurable hotkey.
- Item search by display name, internal name, category and ID.
- Resource batches from 1 to 5000 items with quantity presets.
- Compatible-storage selection, capacity checks and partial-result reporting.
- Cancellation and save/town change handling.
- Eight automated checks for the resource queue.
