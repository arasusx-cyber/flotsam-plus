# Changelog

## 1.0.0 — 2026-11-07

- Independent hunger and thirst switches for the player's town.
- Polish F8 menu with saved need settings and a configurable hotkey.
- Item search by display name, internal name, category and ID.
- Resource batches from 1 to 5000 items with quantity presets.
- Compatible-storage selection, capacity checks and partial-result reporting.
- Cancellation and save/town change handling.
- Eight automated checks for the resource queue.
