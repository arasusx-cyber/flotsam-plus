# Changelog

## 1.0.0 — 2026-11-07

- Added independent hunger and thirst switches for the player's town.
- Added Polish F8 menu and persistent settings.
- Added item search by display name, internal name, category and ID.
- Added resource batches from 1 to 5000 items with quantity presets.
- Added compatible-storage selection, capacity checks and partial-result reporting.
- Added cancellation and save/town change handling.
- Added eight queue checks and a GitHub-ready source distribution.

The binary in this release is the original build confirmed working by the user.
